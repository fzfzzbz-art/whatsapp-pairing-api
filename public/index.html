How to connect

Four quick steps

Use the same flow as the reference site: number, code, linked devices, done.

01

Enter your number

Include country code, no spaces or symbols except an optional leading +.

02

Generate code

Copy the 8-letter pair code and keep it ready within the 90-second window.

03

Open linked devices

Go to WhatsApp → Linked Devices → Link a Device on Android or iPhone.

04

Enter the code

Paste the code and the bot will connect instantly to the same session.
