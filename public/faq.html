Open the main pairing page, enter your WhatsApp number with country code (no spaces), accept the usage terms, then click Generate pair code. Copy the 8-letter code, open WhatsApp → Linked Devices → Link a Device on Android or iPhone, and paste the code within the 60-second window. Your bot is active immediately — no signup needed.
Knight Bot ships with 127+ APIs: AI chat, image tools (alive / menu / owner), status auto-read & react, status privacy reactions, anti-link, anti-bad word, anti-bot, anti-bug, live moderation, always-online reconnect, owner sync, external pair-code API, linked-number sync, and a live-settings panel. Everything is toggleable from the settings page.
The pair code is an 8-letter code generated on demand by POST /api/pairing with your phone number. It is valid for about 60 seconds. After expiry you can request a new one instantly. If you'd rather scan, use the QR bridge at /api/qr — it refreshes live each time the page loads.
Yes. Knight Bot uses the official WhatsApp Linked Devices API — the same protocol WhatsApp Web uses. However, using third-party bots technically violates WhatsApp's Terms of Service. We strongly recommend linking a secondary WhatsApp number only. Your session credentials are stored encrypted on disk and mirrored to MongoDB so the linked number stays connected across restarts.
No. Pairing is 100% anonymous — no signup, no email, no payment, no API token. Open the site, enter your number, generate a code, paste it in WhatsApp. That's the entire flow.
After pairing, open the /settings panel. You can change:
  • Bot name and pack watermark
  • Auto-read status (on/off) and current status emoji
  • Status auto-react and private status reactions
  • Auto-reply toggle and reply template
  • Command mode: public, private, inbox, group, or admin
  • External pair-code API endpoint + token
  • Linked-number sync webhook + token
Changes apply instantly to the linked number — no restart required.
Knight Bot includes a reconnect monitor that keeps an already-linked number on the same session. On Render's free plan, instances spin down after inactivity and may take ~30–50 seconds to come back — the reconnect loop handles this automatically once you trigger a message or scan the QR again. For 24/7 uptime, upgrade the Render plan; pairing credentials are persisted to MongoDB so they survive spins.
